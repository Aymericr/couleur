# Geist fonts

Unmodified TrueType files from [Vercel's Geist v1.7.2 release](https://github.com/vercel/geist-font/releases/tag/v1.7.2), licensed under the bundled [SIL Open Font License](OFL.txt).

- Geist Regular, Medium, SemiBold, Bold: interface text.
- Geist Mono Regular, Medium, SemiBold: color codes and numeric values.
- Geist Pixel Square: compact Couleur wordmark.

The build copies this directory into the app. Core Text registers the faces for the app process at launch; they are not installed system-wide. Native macOS menus and system dialogs retain their platform typography.
